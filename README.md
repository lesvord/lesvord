# Barbarian Saga (Kivy prototype)

"Barbarian Saga" — мобильный прототип, вдохновлённый классической флеш-игрой
"Варвары". Теперь внутри одного приложения собраны игровые активности, необходимые
для полноценного цикла героя: от регистрации до рейдов на боссов.

## Активности и возможности

- Регистрация и авторизация с выбором роли (игрок/администратор).
- Админ-панель для просмотра всех созданных героев и их прогресса.
- Социальные функции: общий чат клана с журналом последних сообщений.
- Боевая арена с быстрыми дуэлями и ростом характеристик героя.
- Экспедиции с разной сложностью и добычей.
- Поля сражений против боссов с возрастающей опасностью.
- Карта мира с вражескими лагерями, деревнями и тайниками — касание экрана задаёт
  новое направление движения героя.
- Экран параметров персонажа с актуальными характеристиками.

## Запуск

1. Установите зависимости (Kivy должен быть установлен в текущем виртуальном окружении):

   ```bash
   pip install -r requirements.txt
   ```

2. Запустите игру из корня репозитория:

   ```bash
   python main.py
   ```

3. На стартовом экране создайте нового героя или войдите под существующими
   данными и изучайте доступные разделы.

> Примечание: текущая реализация хранит данные в памяти процесса. Для демонстрации
> функциональности достаточно запустить приложение напрямую из репозитория.

Для сборки мобильной версии используйте инструменты Kivy (Buildozer/pyinstaller)
в зависимости от целевой платформы.

## Проверка и автоматические тесты

Если вы хотите убедиться, что внутренняя логика работает даже без графического
интерфейса, воспользуйтесь модульными тестами. Они имитируют регистрацию,
переключение активностей, сражения и работу чата через `SessionManager`.

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

После выполнения команда покажет успешный прогон сценариев арены, экспедиций,
битв с боссами и передачи сообщений. Тесты используют заглушки случайности,
поэтому результаты воспроизводимы даже без графического интерфейса.

## Структура проекта

- `main.py` — точка входа Kivy-приложения, экранный менеджер и активности.
- `barbarian_game/entities.py` — базовые игровые сущности.
- `barbarian_game/state.py` — игровая логика карты и столкновений.
- `barbarian_game/session.py` — управление аккаунтами, чат и PvE-активностями.
- `barbarian_game/barbarian.kv` — описания интерфейса Kivy.

Проект разработан как стартовая точка; вы можете расширять его новыми типами миссий,
улучшениями персонажа, диалогами и визуальными ресурсами.
