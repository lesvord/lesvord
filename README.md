# Barbarian Saga (Kivy prototype)

"Barbarian Saga" — это новая мобильная игра, вдохновлённая классическими флеш-"Варварами".
Прототип написан на Python с использованием Kivy и предназначен для быстрых экспериментов
на настольных и мобильных устройствах.

## Возможности

- Интуитивное управление касаниями: нажмите на карту, чтобы задать варвару новую цель.
- Система выносливости, ярости и добычи, влияющая на сражения и развитие героя.
- Посёлки, вражеские лагеря и тайники с припасами, распределённые по карте.
- Простая визуализация с маркерами целей и статусной панелью.

## Запуск

1. Установите зависимости:

   ```bash
   pip install kivy
   ```

2. Запустите игру:

   ```bash
   python main.py
   ```

Для сборки мобильной версии используйте инструменты Kivy (Buildozer/pyinstaller) в зависимости
от целевой платформы.

## Структура проекта

- `main.py` — точка входа Kivy-приложения.
- `barbarian_game/entities.py` — описания игровых сущностей.
- `barbarian_game/state.py` — игровая логика и симуляция столкновений.
- `barbarian_game/barbarian.kv` — описания интерфейса Kivy.

Проект разработан как стартовая точка; вы можете расширять его новыми типами миссий,
улучшениями персонажа, диалогами и визуальными ресурсами.
