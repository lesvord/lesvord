# Barbarian Saga WAP Edition

"Barbarian Saga" превратилась в браузерную WAP-MMORPG, вдохновлённую мобильными
сетевыми RPG нулевых. Интерфейс построен на простых HTML-страницах без
интерактивной карты: игроки переходят между разделами через ссылки и формы,
следя за прогрессом персонажа, экипировкой и событиями клана.

## Возможности

- **Регистрация и авторизация** с ролями игрока и администратора.
- **Панель администратора** с обзором всех героев и их экипировки.
- **Клановый чат** с журналом последних сообщений и приветствиями новых игроков.
- **Боевая арена** против ИИ-соперника: победы приносят опыт и золото, поражение
  снижает энергию.
- **Экспедиции** в зоны разной сложности с добычей ресурсов и артефактов.
- **Битвы с боссами** за эпическую добычу и уникальные предметы.
- **Параметры персонажа и экипировка**: сила, ловкость, дух, выносливость и
  мудрость суммируются с бонусами предметов. Слоты — оружие, броня, амулет,
  головной убор и аксессуар.
- **Статичная карта мира** в стиле ASCII: служит атмосферным фоном и не требует
  взаимодействия.

## Запуск игры

1. Приложение не требует внешних библиотек: достаточно стандартного Python 3.11.

2. Запустите встроенный сервер WSGI:

   ```bash
   python main.py
   ```

   Сервер слушает `http://127.0.0.1:5000` и обслуживает WAP-страницы прямо из
   репозитория. При необходимости можно изменить хост и порт, передав аргументы
   в `app.serve()` внутри `main.py`.

3. Откройте браузер и перейдите на адрес сервера. Домашняя страница содержит
   статичную карту, формы входа и регистрации. После авторизации появится доступ
   к панели героя, чату, арене, экспедициям и боссам.

> Все данные хранятся в памяти процесса. Для демонстрации возможностей
> достаточно запустить сервер прямо из репозитория.

## Проверка логики

Модульные тесты используют встроенный тестовый клиент минимального веб-фреймворка
и покрывают ключевые сценарии:
регистрацию, авторизацию, чат, арену, экспедиции, боссов и экипировку.

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

## Структура проекта

- `main.py` — запуск минималистичного WAP-сервера и определение маршрутов.
- `barbarian_game/models.py` — игроки, характеристики и предметы экипировки.
- `barbarian_game/session.py` — менеджер сессий, чат, арена, экспедиции и боссы.
- `barbarian_game/miniapp.py` — облегчённый веб-фреймворк без внешних
  зависимостей.

Проект можно расширять новыми зонами, типами предметов и интеграцией с
постоянным хранилищем данных.
